# B300 SXM6, TP=1 — the newest card, and not the fastest one — 2026-09-03

275 040 MiB, PCIe gen 6, a 1 100 W cap, compute capability 10.3. It beats
an H100 by 66 % on Qwen3-8B and **loses to it on gemma-4-26B-A4B**, at
1.8x the hourly price.

Hoppers chose FLASH_ATTN, so machine and backend move together in that
column. vLLM 0.28 has no flag for the decoder's backend -- `attention_backend`
exists only in `config/speculative.py`, read out of the installed package --
so the control that would separate them was not available.
