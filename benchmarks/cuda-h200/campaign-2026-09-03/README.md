# H200-143GB-HBM3e, TP=1 — the one card that moves bandwidth alone — 2026-09-03

An H200 is an H100 with more memory: same compute capability 9.0, same
700 W cap, same 1 980 MHz SM ceiling, same PCIe generation, 143 771 MiB
against 81 559. Every other pair in the rented catalogue moves several
things at once. This one is the test of whether `mem_busy` predicts what
more bandwidth is worth, and `PREDICTION.md` was committed before the
data arrived.

**The ordering came back right at both ends and the magnitude did not.**
Predicted spread 0.114 between the most and least memory-bound model,
measured 0.210; `B8` at 1.254x exceeds the memory-clock ratio 1.222 that
the prediction used, which that form cannot produce. Ordinal, not
cardinal. The arithmetic is in `PREDICTION.md`, unedited.
