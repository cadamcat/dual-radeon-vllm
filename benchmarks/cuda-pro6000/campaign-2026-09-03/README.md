# RTX PRO 6000 Blackwell, TP=1 — sm_120 and GDDR7 — 2026-09-03

The workstation Blackwell die, the closest thing in a datacentre catalogue
to the consumer parts this repository is about. It is slower than an H100
on all six models, and **how much slower tracks `mem_busy`**: 0.554x on
the model whose memory controller runs at 87 % and 0.827x on the one at
38 %, monotone across all five in between. The same quantity that says
what a second card is worth says what slower memory costs.

It is also the only machine here that routes gemma-4 to **TRITON_ATTN**,
and within this one card the split is stark: the three Triton arms lose
39-52 % between 500 and 128 000 tokens and the two FlashAttention arms
lose 13-28 %. Backend is confounded with model, so this is not
attribution -- but it is one card in one sitting.

**6 configurations, 91 measurements, 0 errors.** Part of the rented sweep of 2026-09-03; the cross-machine reading, the two platform controls and the collective are in [`cuda-modal/README.md`](../../cuda-modal/README.md).
